# 电工考证题库（网页修复版）

基于朋友提供的电工题库源码制作的独立网站。保留蓝色界面、低压/高压切换、顺序/随机/章节练习、错题、收藏、背题、智能组卷、考试、统计和打卡功能。原作者署名“三玖”保留。

## 本地使用和部署

无第三方运行依赖，Node.js 20 或以上即可。

```sh
node build.mjs
node --test tests/*.test.cjs
```

将 `dist/` 目录交给静态网站服务器。Render Blueprint 配置位于 `render.yaml`，构建命令 `node build.mjs`，发布目录 `dist`。更新任何网页资源后请重新运行构建，离线缓存版本会根据文件内容变化。

## 数据范围

- 低压：1303 题；高压：1436 题；全部保留原始顺序和原始题号。
- 65 张原始题图和 3 个启动图标一起预缓存。页面显示“离线题库已就绪”后可离线刷题。
- 高压第 1409 题的原始资料缺少配图。保留题目、明确提示、禁用作答，不进入模拟考试或背题。
- 原始资料中低压 36 题、高压 121 题没有解析；未编造解析。
- 答案和专业内容沿用提供的原始题库；完整性检查不等于官方考试题库认证，也不等于逐题专业审定。
- 章节为原项目按关键词自动分类，并非官方章节结构。

## 学习记录与备份

记录保存在当前设备、当前浏览器和当前网站域名下。网页版现在可在“我的”中导出/导入 JSON 备份；导入前会校验并确认。版本 3 备份带原始题目 ID，版本 2 安卓备份按本地源码题序兼容。未知版本会拒绝导入，避免错题与收藏错位。

原 Netlify 网站的浏览器记录不会自动转移至新域名。原网站低压题库少了一道题、且重新编号，不能直接照搬它的数组索引。不要在未核对来源时手工复制浏览器存储。

网页版无法保证关闭浏览器后的定时提醒，已在设置中说明；安卓壳原有提醒接口仍兼容。
